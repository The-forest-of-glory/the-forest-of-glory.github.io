# 智慧教室管理信息系统 Web 展示

这是一个基于 Web 技术开发的智慧教室管理信息系统展示网站，用于全面展示系统功能、架构设计、参与者角色和商业模式。

## 项目结构

```
smart-classroom/
├── index.html          # 首页
├── features.html       # 系统功能页面
├── architecture.html   # 平台架构页面
├── roles.html          # 参与者角色页面
├── business.html       # 商业模式页面
├── css/
│   └── style.css      # 主样式文件
├── js/
│   └── script.js      # JavaScript 交互
└── images/            # 图片资源目录
```

## 功能特点

### 1. 首页 (index.html)
- 系统概述和核心价值主张
- 问题分析与解决方案展示
- 六大核心功能模块预览
- 物联网四层架构简介
- 市场前景数据展示

### 2. 系统功能页面 (features.html)
- 智能空间管理：可视化地图、智能推荐、分级预约
- 设备运维管理：扫码报修、智能派单、预测性维护
- 智慧考勤系统：人脸识别、无感签到、数据分析
- 环境智能调控：光照调节、温湿度控制、场景模式
- 智能录播分析：PPT自动同步、学情分析、多机位录播
- 虚拟数字助教：24小时答疑、个性化辅导、知识管理
- 功能对比表格展示传统模式与智慧模式的差异

### 3. 平台架构页面 (architecture.html)
- 物联网四层架构详细说明
  - 应用层：多终端用户交互界面
  - 平台层：数据中台、业务中台、AI引擎
  - 网络层：5G/WiFi6、物联网网关、边缘计算
  - 感知层：环境传感器、视觉设备、控制设备
- 核心技术栈展示
- 数据处理流程图
- 安全保障体系

### 4. 参与者角色页面 (roles.html)
- 双边市场模型展示
- 需求侧、平台方、供给侧关系图
- 7类参与者角色详细说明
  - 学生、教师、管理员、运维人员
  - 决策者、设备厂商、内容服务商
- 每个角色的权限、价值和功能

### 5. 商业模式页面 (business.html)
- 五大盈利模式
  - 基础建设费（一次性）
  - SaaS订阅费（持续性）
  - 增值服务费（可选）
  - 平台交易佣金（生态）
  - 数据服务费（长期）
- 成本结构分析（固定成本、可变成本）
- 实施挑战与应对策略
- 三年发展规划

## 技术实现

### 前端技术
- HTML5 语义化标签
- CSS3 动画和渐变
- 响应式设计（支持移动端、平板、桌面）
- JavaScript 原生开发
- Font Awesome 图标库

### 设计特色
- 现代化渐变色设计
- 卡片式布局
- 平滑滚动动画
- 交互式导航菜单
- 视觉层次清晰

### 响应式适配
- 桌面端（>768px）：完整功能展示
- 平板端（768px）：优化布局
- 移动端（<480px）：汉堡菜单，单列显示

## 使用说明

### 本地预览
1. 克隆或下载项目文件
2. 在浏览器中打开 `index.html` 文件
3. 或使用本地服务器（如 Live Server）运行

### 部署到 GitHub Pages
1. 将 `smart-classroom` 文件夹推送到 GitHub 仓库
2. 在仓库设置中启用 GitHub Pages
3. 选择部署分支和目录
4. 访问生成的 URL
